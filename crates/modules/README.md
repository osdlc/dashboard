# sitroom-modules

The built-in modules of [sitroom](https://crates.io/crates/sitroom), in bundles chosen with features (`bundle-system`, `bundle-dev`, ... or one `module-<id>`), and the runtime that starts them and plugins from the config. See [docs/modules.md](https://github.com/osdlc/sitroom/blob/main/docs/modules.md).

Part of sitroom, a modular developer dashboard with a terminal UI and a web UI. Most people want
the program: `cargo install sitroom` or `brew install osdlc/tap/sitroom`. Site:
<https://osdlc.github.io/sitroom/>. Licensed MIT or Apache-2.0.
