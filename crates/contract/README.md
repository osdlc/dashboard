# sitroom-contract

The types a [sitroom](https://crates.io/crates/sitroom) module, stdio plugin or renderer shares: a tile's `View` and its widget tree, the module manifest, the plugin JSON-RPC messages, the package catalog and the checks `sitroom plugin-check` runs.

To write a plugin in another language, use the TypeScript or Python SDK instead: see [docs/plugins.md](https://github.com/osdlc/sitroom/blob/main/docs/plugins.md).

Part of sitroom, a modular developer dashboard with a terminal UI and a web UI. Most people want
the program: `cargo install sitroom` or `brew install osdlc/tap/sitroom`. Site:
<https://osdlc.github.io/sitroom/>. Licensed MIT or Apache-2.0.
