# sitroom-core

The core of [sitroom](https://crates.io/crates/sitroom): the config file and saved dashboards, the host that runs modules and plugins and feeds the renderers, and the osdlc command-line conventions (output, exit codes, folders).

Part of sitroom, a modular developer dashboard with a terminal UI and a web UI. Most people want
the program: `cargo install sitroom` or `brew install osdlc/tap/sitroom`. Site:
<https://osdlc.github.io/sitroom/>. Licensed MIT or Apache-2.0.
